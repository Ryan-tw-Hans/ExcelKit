# 啟動頁與版本偵測測試計畫｜ISSUE-0003

依使用者於 2026-11-16「開工」核准 Requirements/RS-ISSUE-0003-startup-links-draft.md，Codex 自查。風險為偵測誤判、未授權寫入、前置條件繞過、路徑混淆、UI 超出尺寸及原 COM 交易退化。

| 項目 | 前置條件及步驟 | 預期與證據 |
|---|---|---|
| 初始畫面 | 隔離環境開啟中英文安裝器，鍵盤點擊兩個下載連結並取消 | 直接開啟正確網頁，沒有安裝或更動 COM；UI 可讀 |
| 目錄 | 分別測試已安裝、不同自訂目錄、缺失、兩登錄視圖衝突 | 僅可確認且存在時開啟正確目錄，其他狀態提示，不建立資料夾 |
| 版本 | 測試空白、x86／x64、登錄與檔案不一致、不同或相同雜湊、缺失 DLL、HKCU 覆寫、多版本、拒絕讀取 | 正確標示類型及未知狀態；不把登錄版本當實際檔案版本；不執行 DLL 或寫入登錄 |
| 前置條件 | 缺少 Framework 的隔離機，互動及靜默繼續安裝 | 可顯示歡迎頁；安裝前明確阻止，無檔案及 COM 變更 |
| 回歸與回復 | 原新安裝、升級、取消、失敗注入、COM x86／x64、完成頁選項 | 依既有計畫通過，COM 備份回復正確；保留 log |
| 建置與安全 | 驗證包內 DLL 版本／雜湊、版本號、固定輸出與來源一致 | 一致且可追蹤，記錄環境、命令、雜湊 |
