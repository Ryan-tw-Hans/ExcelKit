# 可重複打包與安裝驗證測試計畫｜ISSUE-0003

基準 Requirements/RS-ISSUE-0003-repeatable-package-draft.md，使用者已確認；Codex 依序擔任 PM、SA、軟體與測試，自查非獨立審查。

1. 預檢：執行 dry-run，確認不產生輸出、無發布內容變更；模擬缺工具、缺素材、版本不一致及已有同名產物，須明確失敗且保留原始內容。
2. 來源與封裝：以隔離快照編譯 net472／net10.0，核對打包 .iss 版本與 DLL 組件／檔案／產品版本、雜湊及明確素材清單；污染舊 publish 的檔案不可混入。產出固定位置、記錄 SHA-256 與工具版本。兩次不同版本各使用空白 staging；同版重跑不可覆寫。
3. 安裝後驗證：以人工建立的暫存安裝樣本驗證已選／未選、雜湊不一致、遺失檔案、無選項紀錄、路徑竄改、COM 註冊不符；唯讀模式不得修改安裝樣本及系統。獨立測試不等於實際安裝。
4. 在 Windows Sandbox 測試真實安裝後的版本、選項與 x86／x64 COM，並測試升級、重裝取消可選項後留存資料、解除安裝、失敗與回復；必要時明確啟用 COM 煙霧測試。隔離環境不可用則標示未執行，不宣稱整體安裝驗收。
5. 驗證 skill frontmatter、腳本入口、文件及範例；COM 功能、印表機、LibreOffice、GUI 及部署不在打包本身的驗證範圍。
