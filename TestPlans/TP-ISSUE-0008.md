# ISSUE-0008｜測試計畫草案 v0.1

測試工程師：Codex，自查非獨立審查。規格與架構尚待確認；此為草案，採用設計後定案。所有結果目前為未執行。

- 基本建置：以指定 commit 在 Windows runner 安裝鎖定工具，還原、編譯、打包，核對輸出、manifest、SHA、DLL 與安裝器版本、排除影片及 commit 來源。
- 配號：同日、跨日、不同 DLL 版本、兩位以上序號、平行分配、跨本機與 CI、重試及重跑；每個成功保留唯一且遞增。
- 失敗與恢復：模擬分配成功後中斷、伺服器回應不明、API 失聯、無權限、ref 已存在、遭刪改與輸出局部存在；驗證不覆蓋、不重用且訊息可診斷。
- 遷移：以獨立 fixture 測試舊本機台帳、舊產物及失敗保留的匯入、衝突、不完整輸入、重複匯入與回退，確認不修改原始資料。
- 整合與安全：不可信事件無分配寫入權限；指定事件能取得最小權限；artifact 可下載、保存策略可見；檢查漏失工具、素材、金鑰及網路錯誤的 fail-closed 行為。
- 相容性：回歸既有本機打包及版本測試；隔離環境確認安裝／升級／回復及 x86/x64 COM，若無環境則標未執行；CI 成功不得代替 GUI、LabVIEW 或實機驗收。
- 證據：記錄 commit、workflow run／attempt、測試環境、命令、版本、SHA 與結果；測試不可使用或刪改正式配號紀錄。
