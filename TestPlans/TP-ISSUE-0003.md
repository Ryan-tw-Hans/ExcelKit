# 測試計畫草案｜ISSUE-0003

版本 v0.2；執行者 Codex（測試工程師，自查），待架構與需求確認後定案。環境：隔離且可還原的 Windows VM、管理員權限、.NET Framework 4.7.2 以上；另需 32 位元 Windows 才能完整確認該平台。

- 自 publish/Installer 中的設定副本編譯，確認正確取得發布內容且不將 Installer 遞迴納入；設定副本與可維護來源一致。
- 乾淨 64 位元系統：安裝成功，檔案雜湊正確，x86 與 x64 登錄指向目標；以兩種 cscript 建立物件，驗證版本及儲存格讀寫。卸載後兩個視圖的本安裝註冊及安裝檔消失、使用者資料保留。
- 重複安裝和升級：確認正確更新、路徑、版本與卸載效果；測試中斷及重新執行。
- 事先存在其他 ExcelKit 登錄：兩視圖逐一測試，安裝須停止並保持既有登錄不變；卸載前更換擁有者須保持其他登錄。
- 權限不足、Framework 缺失、RegAsm 缺失、第一或第二個註冊失敗、卸載註冊失敗：應顯示錯誤，驗證不產生錯誤成功訊息、可回復及重試，前後比較登錄與檔案。
- 32 位元 Windows：安裝與 x86 COM 呼叫、卸載；未提供環境須標示未執行。
- 對每項記錄命令、環境、版號、執行結果與日誌；COM／LabVIEW／LibreOffice 若未驗證分別記錄，不能以檔案存在判通過。


- 位元選擇：64 位元 Windows 依序測試只選 x86、只選 x64、兩者；未選不得繼續。32 位元 Windows 僅可選 x86；解除安裝僅影響原選項。


## 雙語補充測試
編譯時檢查繁體中文及英文語系檔與所有自訂訊息鍵存在；測試語言選擇與顯示文字、Windows 顯示語言預設及無匹配英文後援；無法安全執行正式安裝 GUI 時，先以不寫入登錄的測試程式檢查語言文字，將 GUI 與系統語言自動偵測列為待驗證。

## 最終整合測試範圍
以產品候選安裝檔測試 x86、x64、雙位元新安裝及解除安裝，使用各自位元的 Windows PowerShell 真正啟動 COM、驗證版本與儲存格讀寫。另測試拒絕舊版替換、舊 TypeLib 檔不存在的遷移、移除舊版後失敗、註冊新 x86 後失敗、失敗安裝清理、重新安裝與解除安裝故障回復。故障開關僅編譯進 Sandbox 測試安裝器，不包含於交付安裝檔的 Inno 流程。備份損壞、未完成交易與未知註冊另做助手保護案例；真正斷電與純 32 位元 Windows 未執行，明列限制。
