# 測試計畫｜ISSUE-0003 LibreOffice 可選安裝

基準：Requirements/RS-ISSUE-0003-libreoffice-draft.md，使用者 2026-11-16 同意；Codex 擔任測試工程師，自查非獨立審查。

風險：x64 限制、使用者權限與非 ASCII 路徑、使用者設定、外部 LibreOffice 共存、打包容量、ExcelKit PDF／列印呼叫、升級與回復。必要測試未執行不得算通過。

| 項目 | 前置及步驟 | 預期與證據 |
|---|---|---|
| 來源 | 核對發行者 SHA-256 與版本、授權檔 | 一致；記錄雜湊、來源、大小 |
| 編譯與選項 | 使用固定輸入及 Inno 編譯；檢查中英文、預設及 x86 條件 | 無錯誤；選取與檔案條件一致，記錄命令與輸出 |
| 初裝 | 隔離 Windows x64 勾選與不勾選、標準使用者啟動；測試中文路徑 | 選取才安裝並可啟動及保存設定；記錄 log |
| 重裝／移除 | 有資料時取消選項重裝，再解除安裝 | 保留使用者資料及重裝未選檔案；外部安裝不受影響，記錄前後檔案 |
| 整合 | 隔離環境以 ExcelKit 轉 PDF 和列印，含既有 LibreOffice 共存 | 功能正確並記錄路徑、結果；設備不可用標未執行 |
| 回歸及回復 | 依現有 COM 交易測試、故障注入及回滾流程 | 無既有行為退化，備份回復正確；未測標未執行 |
| 發布檢查 | 測試版版本、固定輸出路徑、雜湊及程序狀態 | 一致，未核准正式版不作正式發布 |
