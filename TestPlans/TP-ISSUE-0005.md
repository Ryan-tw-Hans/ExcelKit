# ISSUE-0005 測試計畫草案 v0.1

測試工程師 Codex，與 PM、SA、開發為同一執行者，非獨立審查。須待需求與架構方案確認後定案。使用獨立隔離目錄、測試版與可用的 Windows Sandbox，不動主機 COM 註冊和使用者文件。

| 項目 | 方法／前置條件 | 通過標準 |
| --- | --- | --- |
| 檔案版本遞增 | 在隔離副本模擬連續兩次更新、同來源重建、較舊／重複號與序號上限 | 新更新數值遞增；同內容策略符合規格；衝突、回退、耗盡明確停止 |
| 元件版本 | 建置 net472/net10，讀取 Windows 檔案屬性與組件 metadata | 兩框架 file version 一致且高於舊版，產品版本一致，AssemblyVersion 維持 1.2.4.0 |
| 靜態 COM 契約 | 比對 IID、CLSID、ProgID、型別庫 ID／版本、方法簽章及所有舊 DispId | 舊契約無不相容變更；該項不能單獨證明執行時相容 |
| 隔離 COM 與升級／回復 | 以 Sandbox 安裝舊版，分別從 x86 與 x64 COM 客戶端測舊方法；升級到新版，測舊與顏色方法，回復舊版並再次測試 | 所有操作與檔案保存正確、登錄狀態合理，保留逐步日誌。Application Control 阻擋即標受阻，不宣稱通過 |
| 功能、範例與文件 | 回歸 ISSUE-0004 RGB、範圍、存檔；使用實際新 DLL 執行範例並檢查手冊版本說明 | 指定內容、值與顏色正確；先於打包完成 |
| 打包 | 以上必要測試成功後預檢並建置測試安裝包，比對清單、版本、雜湊並在隔離環境驗證 | 檔案一致且未覆蓋舊包；新版安裝、驗證與清理成功 |

本測試需舊版可驗證來源及可執行的隔離環境；缺少時標未執行，向 PM 回報而不繞過政策。真正 32 位元 Windows 和 LabVIEW 另列環境限制。效能、資料庫 migration、持續服務維運不適用；登錄及程式升級、回復適用。

2026-11-16：需求與架構 v0.1 已由人類核准，本測試計畫定案；執行者 Codex。
