# ISSUE-0007 測試計畫草案 v0.1

測試者 Codex，與 PM/SA/開發同一執行者，非獨立審查；待需求及架構確認後定案。對應 RS/AR v0.1。

- 在隔離 fixture 以可注入的日期測試首次 01、同日 02、跨日重置、舊版秒級檔案共存、不覆蓋、任一輸出已存在、失敗殘留、預檢與執行衝突、同時請求與時區邊界。需證明不重用且不靜默覆蓋。
- 檢查排除影片不在 staging、manifest、安裝內容，而原影片 hash 不變，其他既有素材保持；測試 Media 為空或缺檔時明確行為。
- 建置並檢查 installer version、檔名、產品資訊、build/manifest/安裝選擇版本一致；DLL 版本規則與 COM 不變，檢查同日新舊格式並存。
- 在 Sandbox 自舊版時間戳 TEST 包升級到新格式、驗證 x86/x64 COM、清單及排除影片、回復舊版；記錄舊版已存在影片保留行為，檢查 GUI 中英日期序號；受阻列未執行。
- 執行既有 package workflow 防竄改與出錯測試，最終重開／回歸及互動測試另分結果。

- 檢查專案打包 skill、build-release 及存在的備援副本與實際腳本一致；測試 skill 格式，確認 DLL 版本規則不受影響。

## v0.3 使用者核准後定案
安裝器檔名及版本的四段前綴必須與實際打包 DLL FileVersion 一致（不只產品基準）；同日期跨不同 DLL 檔案版本的序號仍不得重用。每項依既有流程留下命令、fixture、測試結果與未執行項；軟體、測試、SA 均由 Codex 依序自查，非獨立審查。
