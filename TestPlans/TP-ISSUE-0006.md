# ISSUE-0006 測試計畫 v1.0

測試者 Codex，與開發與設計為同一執行者，非獨立審查。需求與設計草案 v0.1 經人類確認；工作分支 feature/ISSUE-0006-installer-version，main 起點 1ad27cb8a04e6a66f022e9fda164c999e8fafd26，含既有未提交變更。

| 項目 | 步驟與預期 |
| --- | --- |
| 中英標籤 | 確認套件檔案版本與目前已登錄檔案版本標籤不同，兩語訊息鍵及頁面引用一致。 |
| 版本來源 | 打包前以隔離輸出測 metadata 寫入，驗證值來自實際 net472 DLL，並與 csproj、manifest、build report 的 FileVersion 一致；偵測不一致則停止。 |
| 原有功能 | 建置 net472/net10.0、執行既有文字顏色與版本功能測試；COM 識別及已登錄值的讀取邏輯保持不變。 |
| 安裝 UI | 於可用的 Sandbox 測試繁中、英文；已登錄舊版本、新版本相同與未登錄狀態，檢查可捲動、焦點與文字正確。環境不可用標未執行。 |
| 打包 | 全部必要自動測試後先預檢再打包；比較 DLL 檔案版本、組件版本、產品版本、manifest、實際檔案與 SHA-256；執行既有 package workflow 檢查。 |
| 安裝及回復 | 能執行時在隔離環境測候選包升級、x86/x64 COM 與舊版回復；結果與 UI 測試分別記錄。不得更動主機 COM 登錄。 |
