# 測試計畫｜ISSUE-0003 LibreOffice 下載連結

基準：RS-ISSUE-0003-libreoffice-links-draft.md，使用者已確認。Codex 擔任測試工程師，屬自查。

| 項目 | 前置及步驟 | 預期結果與證據 |
|---|---|---|
| 編譯及內容 | 以固定發布輸入及 Inno 編譯，檢查連結文字檔及腳本 | 編譯成功，兩個網址與說明正確 |
| 完成頁 | 隔離 Windows 互動安裝，以中英文分別檢查四種選擇 | 均預設不勾選；僅選取的頁面於成功安裝後由瀏覽器開啟 |
| 靜默與失敗 | 隔離環境 /SILENT 和 /VERYSILENT；注入 COM Apply／Finish 失敗 | 不開啟瀏覽器，失敗顯示正確，回復流程不受影響 |
| 升級及移除 | 隔離環境升級安裝及解除安裝，檢查連結檔與其他使用者資料 | 連結檔正確更新及受控移除，無關使用者資料保留 |
| COM 回歸 | 隔離環境執行既有 x86／x64 註冊、COM 客戶端、交易故障注入測試 | 註冊、回復及解除安裝依原規格運作 |
| 版本及輸出 | 確認測試版號、固定輸出路徑、雜湊及執行中的程序 | 記錄證據，正式基準不變 |

## 安裝資料夾選項

乾淨隔離環境下檢查中英文完成頁預設不勾選；勾選後按完成應開啟所選安裝目錄，不勾選不開啟。搭配兩個下載連結測試各項可獨立選擇，靜默安裝及 COM 交易失敗時不開啟；保留實際 log 與結果。必要測試未執行不得視為通過。
