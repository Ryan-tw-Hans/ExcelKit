# 安裝選擇設計｜ISSUE-0003

Codex（設計工程師，自查）；使用者要求安裝時選擇 x86 或 x64。使用 Inno 標準元件選擇頁，不增加自訂視覺。64 位元 Windows 提供 x86（32 位元客戶端）和 x64（64 位元客戶端），允許只選一項或同時選兩項；32 位元 Windows 僅顯示 x86。至少選一項，未選時說明並阻止繼續。清楚標示這是客戶端位元數，保留鍵盤及螢幕閱讀器可用的標準控件。使用者已明確要求選擇功能；兩者可同時選取是為滿足既有雙位元需求的實作選擇。

## 安裝語言選擇（2026-11-15）
依使用者確認，提供繁體中文與英文，預設依使用者 Windows 顯示語言，其他語言預設英文；開啟標準語言選擇對話框，允許手動切換。選項與自訂訊息均需翻譯，沿用系統字體與 Inno 標準版面，無動畫與客製介面。驗收：兩語言完整、切換有效、預設值及未匹配後援正確；以可用方法檢查，GUI 未執行需明列。
