# ISSUE-0007 安裝包日期序號與影片排除｜需求草案 v0.1

狀態：待確認；PM：Codex。類型變更，L3，因改變發布產物版本與既有安裝器資料契約。使用者要求打包時排除 `Video_2026-08-15_233419.mp4`，安裝包版號日期到 yyyyMMdd、同日使用 -01、-02 等序號，檔名不含 TEST，例 `ExcelKit-Setup-1.2.4-20261116-01.exe`。

## 建議規則
1. 安裝器版本與顯示、報告、清單及安裝選擇紀錄採 `<正式基準>-<台北日期 yyyyMMdd>-<當日序號>`；本專案首次新格式當日為 `1.2.4-20261117-01`，下一個為 `-02`；示例不是正式版。安裝包檔名為 `ExcelKit-Setup-<安裝器版本>.exe`；同名 manifest/build JSON 同步。序號至少兩位，按數字遞增，遇到已存在輸出、失敗殘留、併行任務或無法判定唯一性時不覆寫、應安全停止或分配下一個未用號。舊的時間戳 TEST 包保留且可查，不將原檔改名；新格式從 `01` 起算。
2. 原則為台北日期（Asia/Taipei）。先預檢並固定版本，打包全程沿用；不能因跨午夜而改名。僅新格式的安裝器顯示／紀錄與檔名採日期序號；DLL 產品版本延續已核准時間戳格式與檔案版本遞增規則，COM 組件識別及正式版基準不變。移除 TEST 是檔名要求，不是正式發布指令；報告仍標示測試版。
3. 排除指定影片，其他 Media 素材、手冊、範例與安裝選項維持；來源 `Reference/Media/Video_2026-08-15_233419.mp4` 與舊安裝包均保留。不將排除文件加入 staging、安裝清單或新安裝；曾由舊版安裝的影片是否移除不在本次範圍，現有使用者資料不得自動刪除。
4. 測試及文件更新涵蓋新舊版本格式、同日序號、跨日、重複、部分輸出、併行衝突、影片不進包、其他素材仍在、簽章／雜湊清單與安裝後驗證。以 Windows Sandbox 測試舊版升級與回復及 x86/x64 COM，不操作主機登錄。若環境或政策受阻，標示未執行。
