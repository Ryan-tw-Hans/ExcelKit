# LibreOffice 可選安裝方案草案｜ISSUE-0003

狀態：待人類確認；執行者：Codex（PM、SA、設計工程師、系統整合及維運；非獨立審查）。本項延續 ISSUE-0003 的 L3，尚未核准開發。

## 目標與方案

將 LibreOffice Portable 作為 Inno Setup 的獨立可選項目，供需要 LibreOffice 的使用者離線使用。建議使用 PortableApps.com 發行的 26.2.4 MultilingualStandard（含繁體中文，僅 Windows x64），先驗證發行者雜湊；包入程式檔及必要授權資訊。安裝精靈沿用既有中英文標準任務清單，項目名稱「LibreOffice 免安裝版」，首次預設不勾選；x86 Windows 不提供此選項。安裝位置建議為 ExcelKit 目錄下的獨立子目錄，建立可選的開始功能表捷徑。重新安裝時取消勾選不主動刪除既有檔案；解除安裝只移除安裝器管理的檔案，保留使用者資料。實際打包格式與捷徑應先驗證 PortableApps 的啟動器及資料目錄權限。

## 架構與選項

目前 Installer/ExcelKit.iss 的手冊、範例與 .NET 10 採 Inno Tasks 和檔案清單；沿用此模式最一致。替代方案是只放下載連結、安裝時再連網下載，可縮小主安裝包，但無法離線使用且受網路影響。建議離線內嵌；套件會顯著增加安裝包與磁碟用量。發行者指出非 ASCII 安裝路徑可能有問題，且 portable 程式的使用者設定可能需要可寫位置，須在含中文路徑、標準使用者及升級／解除安裝情境驗證；若無法安全滿足則停止並回報，不逕改系統設定。與既有 LibreOffice 共存及 ExcelKit PDF／列印整合需確認。版本、授權與散布條件須記錄並檢查。

## 適用性

- 架構：適用，新增第三方程式及打包依賴；SA 建議有條件採用。
- UI：適用，沿用標準勾選項，預設不勾選；待確認。
- 資料庫：不適用，未變更應用程式資料庫。
- 系統整合：適用，需測試 LibreOffice 啟動與 ExcelKit 的 PDF／列印路徑及相容性。
- 維運：適用，需驗證更新、升級、解除安裝、使用者設定保護及來源雜湊。

## 驗收草案

1. 選取時安裝可啟動的繁中可攜版；不選時不安裝；32 位元 Windows 不提供不相容選項。
2. 確認 Windows 標準使用者可執行並保存設定，含中文路徑；與既有 LibreOffice 共存；不修改其安裝。
3. 檢查升級、取消選擇、解除安裝、使用者資料保留與靜默安裝；驗證既有 COM 行為無回歸。
4. 檢查下載雜湊、授權及散布條件，記錄版本、來源及安裝包大小。於隔離環境驗證 PDF／列印，未執行者明確標示。
5. 輸出位置沿用 publish/Installer/Setup；正式版基準不變，測試版依既有版本策略進版。
