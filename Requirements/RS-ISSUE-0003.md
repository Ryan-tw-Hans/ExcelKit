# 需求規格草案｜ISSUE-0003｜Inno Setup 安裝程式

版本：v0.3；v0.2 已由使用者於 2026-11-14 核准，v0.3 納入使用者要求安裝時選擇 x86／x64；等級：L3（機器層級 COM 註冊、權限及安裝方式）。執行者：Codex（PM）。

## 目標及範圍
提供可重建的 Inno Setup 腳本與 Windows 安裝檔，安裝既有 publish 下的 net472、net10.0、Manual、Examples、Media，維持分類。以管理員權限安裝 net472 COM 元件；安裝時可選 x86、x64 或兩者；32 位元 Windows 只允許 x86，64 位元 Windows 可選 x86、x64 或兩者。支援自動解除各自建立的註冊及解除安裝。正式版基準 1.2.4；本次為獨立時間戳測試版。核心元件位於 src/Excelopen，安裝檔建議固定放在 publish/Installer；Inno Setup 設定腳本與建置說明也複製到 publish/Installer/；腳本以相對路徑參照 publish 中的 bin、Manual、Examples、Media，並將安裝檔輸出至同一 Installer 目錄。打包輸入明確排除 Installer，避免遞迴打包；另保留專案內可維護的設定來源。

## 行為及驗收條件
1. 安裝前檢查 .NET Framework 4.7.2 以上、管理員權限、適用的 RegAsm 與衝突的既有 COM 註冊。缺少必要條件或發現非本安裝程式擁有的註冊時停止並提供明確訊息，不覆寫或刪除既有註冊。
2. 全新安裝後，使用 32 位元與 64 位元 cscript 分別建立 ExcelKit.ExcelOperator，讀取版本並建立、寫入及讀取活頁簿；核對兩登錄檔視圖所指 DLL 與安裝目錄及版本。
3. 解除安裝先檢查目前註冊仍屬於本次安裝，然後解除註冊；不得移除其他安裝或被其他程式接管的註冊。移除由安裝程式建立的檔案，保留使用者自行建立的資料。
4. 安裝／註冊任一步失敗須顯示失敗，不得回報成功；設計回復並驗證部分註冊失敗、解除安裝失敗及重試；不依賴靜默忽略 RegAsm 錯誤。
5. 測試全新安裝、解除安裝、重複安裝、升級、衝突保護、權限／前置條件不足、安裝中斷與回復；保留日誌、版本、雜湊與結果。64 位元 Windows 驗證雙位元；32 位元 Windows 獨立驗證或明列未執行。

## 適用性
- 架構：適用，新的安裝及系統 COM 註冊，見 Architecture/AR-ISSUE-0003.md。
- UI／視覺：適用安裝選擇，採 Inno 標準元件選擇頁；清楚標明 32／64 位元，至少選一項；沿用標準介面而不自訂視覺。
- 資料庫：不適用，無應用資料庫修改。
- 系統整合：適用，涉及 Windows、.NET Framework、VBS／LabVIEW COM 客戶端與 32／64 位元註冊。
- 維運：適用，涉及升級、解除安裝、衝突保護與回復。

## 限制及待確認
目前主機兩個視圖都已有 ExcelKit 1.2.0.0 COM 註冊指向既有 Debug DLL；目前工作程序非管理員。為避免破壞既有設定，建議在乾淨的可還原 Windows VM 進行真正安裝及卸載測試；目前尚未找到可用 VM。LibreOffice 隨附及自動安裝不在範圍；PDF／列印另需既有 LibreOffice。COM 啟動與安裝測試不可由靜態檢查代替。

## 發布目錄分類補充（2026-11-15）
依使用者指示，`publish/Installer/Setup/` 放打包完成的安裝程式；`publish/Installer/Config/` 放 Inno Setup 設定與建置說明。設定檔以相對路徑參照 `publish/bin`、`Manual`、`Examples`、`Media`，並輸出至 Setup。舊測試安裝程式移至 Setup 保留，避免覆寫。既有 COM 處理和未完成隔離測試的狀態不變。
