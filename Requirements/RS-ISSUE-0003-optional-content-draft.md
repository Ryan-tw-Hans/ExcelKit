# 需求與介面方案草案｜ISSUE-0003｜可選安裝內容

狀態：使用者於 2026-11-16 確認以下方案及 net10.0 獨立選項；執行者：Codex（PM、設計工程師；非獨立審查）。沿用 ISSUE-0003 的 L3 等級與既有 COM 註冊、舊版移轉及回復規格。

## 目標與建議方案

安裝時沿用 Inno Setup 標準介面，提供三個可獨立勾選的項目：「操作手冊」、「範例程式」及「net10.0 元件」。初次安裝前兩項預設勾選，net10.0 預設不勾選。Media 隨手冊安裝。三者皆不勾選時，只安裝及註冊 COM 所需的 net472 元件與維護檔；仍須選擇至少一種 x86／x64 客戶端位元數。保留繁體中文及英文。

已安裝版本重新執行時，取消勾選保留先前安裝的檔案及使用者資料，不主動刪除；若要移除以解除安裝處理。新安裝的捷徑僅為選取的項目建立；重新安裝的捷徑行為須實測確認。

## 驗收草案

- 三個選項八種組合可選擇並安裝對應檔案與捷徑；全部不選時仍能依選擇註冊 COM。
- 不變更既有 COM 衝突保護、移轉確認、交易備份／回復及 x86／x64 選擇行為；在隔離 Windows 環境測試註冊、升級與解除安裝。
- 驗證中英文文字、預設值、重新安裝／升級與靜默參數行為；核對使用者自行建立檔案不被移除。無法執行的項目記為未執行。

## 適用性與後續

- 架構：適用；安裝組件及註冊相依性需 SA 確認。資料庫：不適用，未修改應用資料庫。
- UI：適用；採標準控制項，確認選項與預設值。系統整合：適用，需驗證 COM 客戶端及位元數。維運：適用，需驗證升級、解除安裝及回復。
- 沿用 feature/ISSUE-0003-installer，起始主線 main commit 1ad27cb8a04e6a66f022e9fda164c999e8fafd26；安裝器來源 Installer，固定設定與測試版輸出分別為 publish/Installer/Config 與 publish/Installer/Setup。正式版基準 1.2.4，安裝器更新採時間戳測試版，不改變 DLL 的組件版本；正式合併仍須人類核准。
