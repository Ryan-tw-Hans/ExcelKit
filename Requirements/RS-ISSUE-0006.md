# ISSUE-0006 安裝畫面顯示套件 DLL 檔案版本｜需求草案 v0.1

狀態：待人類確認。PM／設計／測試由 Codex 依序執行，自查非獨立審查。類型：缺陷；等級 L2，因需更新安裝介面與設計驗收。背景：現有畫面列套件產品與組件版本，已登錄 DLL 區域才列其檔案版本，未列套件 DLL 的檔案版本；使用者無法直接對照。

## 範圍與驗收
- 顯示本次套件 DLL「檔案版本」，來源為實際打包 net472 DLL 的 FileVersion，應與 manifest、建置報告一致；不得使用安裝時已登錄 DLL 值代替。
- 現有 x86/x64 區域的「DLL 檔案版本」明確標示為「目前已登錄 DLL 檔案版本」；未登錄或讀取失敗維持正確提示，不憑空顯示版本。
- 既有套件產品版本、組件版本與 SHA-256 比對保留；不改 COM 識別、註冊、覆寫或安裝選擇。英文及繁體中文標籤一致。
- 測試全新安裝狀態、舊版已安裝及已安裝相同版本，核對新舊檔案版本、hash 與標籤，並驗證 UI 無截斷、可捲動、鍵盤操作；文字、版本來源與打包一致。環境不可用的互動 UI 項目標未執行。
- 根據 ISSUE-0005 版本規則，為新的測試更新分配較高且未重用的產品時間戳及 FileVersion（候選 `1.2.4.2`，以當時台帳與已安裝版本檢查為準）；AssemblyVersion 維持 `1.2.4.0`，正式基準不變。先測試再打包，不覆蓋前版。

## 五項適用性
架構：不適用，局限安裝器既有 metadata 與文字顯示，無系統邊界或介面契約變更；若實作觸及原安裝／註冊交易則重新評估。UI：適用，見 DesignPlans/DP-ISSUE-0006.md。資料庫：不適用，無產品資料庫變更。系統整合：不適用，僅展示現有來源值，不修改 COM 介面或註冊。維運：不適用，無持續服務或維運流程變更。

## 影響與限制
安裝器程式 `Installer/`，元件 `src/Excelopen/`，測試包 `publish/Installer/Setup/`。實作需依需求與設計確認後完成測試計畫及功能分支；既有未提交變更須保留。Sandbox 實際 UI 檢查及 LabVIEW 視環境可用性如實回報；不自動在主機安裝、合併或發布正式版。
