# 需求草案｜ISSUE-0002｜分類發布與編譯

狀態：分類及版本基準已由使用者於 2026-11-14 確認；等級：L3（固定發布位置及發布方式需架構評估）。執行者：Codex（PM）。

## 目標與範圍
Release 建置後將 ExcelKit 元件、手冊及教學資料分類放入專案 `publish/`，並編譯 net472 與 net10.0。現有專案檔已定義 `publish/bin/<框架>/`、`publish/Manual/`、`publish/Examples/VBS/`、`publish/Examples/LabVIEW/`、`publish/Media/`；先以此作為建議配置。程式資料夾為 `src/Excelopen/`。

## 驗收條件
1. Release 編譯成功，兩個目標框架的元件出現在對應資料夾。
2. Reference 中的手冊、VBS 與 LabVIEW 範例、媒體，依上述類型複製；來源與輸出清單及雜湊一致。
3. 版本與程式可讀版本一致；發布前檢查目標程序與既有輸出，避免覆寫無關資料。
4. 檢查後續 Release 建置可重現輸出，並記錄測試限制。

## 適用性初判
- 架構：適用，固定發布位置變更；評估見 Architecture/AR-ISSUE-0002.md。
- UI／視覺：不適用，無介面改動。
- 資料庫：不適用，無應用資料庫改動。
- 系統整合：不適用，未變更外部介面；COM 實際註冊與客戶端測試另列限制。
- 維運：適用，發布位置及內容需明確、可重現並避免覆寫無關檔案。

## 待確認與限制
使用者確認 1.2.4 為正式版基準及上述分類；本次產生時間戳測試版，不變更正式版基準。保留目前所有未提交變更；不執行 COM 註冊、對外發布或合併。
