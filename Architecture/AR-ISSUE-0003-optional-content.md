# 可選安裝內容架構評估｜ISSUE-0003

Codex 扮演 SA、系統整合與維運，自評；2026-11-16。使用者確認三個獨立選項與預設值。既有安裝來源 Installer/ExcelKit.iss 一律複製 net472、net10.0、Manual、Examples、Media；COM 交易由 ComTransaction.ps1 處理，僅 net472 註冊。可選檔案不改變系統信任邊界及註冊交易契約。應保留必要 net472 與助手，將 net10.0、Manual／Media 及 Examples 按選項限制，對應捷徑同樣受限制。既有外部 LibreOffice 等依賴、登錄備份回復及管理員權限不變。

比較：維持全裝無法滿足需求；以標準 Inno 任務控制檔案及捷徑可涵蓋所有組合且不引入自訂安裝邏輯，採後者。net10.0 為獨立組件，不依賴 COM 註冊。升級取消勾選不主動刪除舊檔以保護資料，故不等同移除既有項目；解除安裝時 Inno 對曾安裝檔案與使用者資料的處理須實測。系統整合須實測 x86／x64 COM 呼叫；維運須實測安裝、升級、卸載、失敗回復及留存日誌。無應用資料庫變更。

結論：有條件採用；要求隔離 Windows 驗證選項、升級、卸載及原交易回歸，測試結果未取得前不可視為維運就緒。實作後符合性待核對。

版本 1.2.4+20261116091614：腳本中 net472 與交易助手為必要檔，net10、手冊及媒體、範例和各自捷徑受任務限制；交易助手的來源及 Config 副本雜湊一致。靜態符合方案；實際 COM、升級／卸載、回復與使用者資料保留未在此版本驗證，因此整體符合性及維運就緒仍待確認。
